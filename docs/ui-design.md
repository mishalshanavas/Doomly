# Doomly UI

Doomly is a playful Instagram Reels scorekeeper. The product research and feature mapping are in [brainpal-research.md](brainpal-research.md).

Cream surfaces, espresso text, warm gold progress, serif page headings, and generous spacing form the shared visual system. Use semantic theme colors for readable content. Rounded navigation keeps visible labels and accessible tab roles.

Home leads with the real daily tally and editable target. Target completion never stops counting. Mochi's five daily levels are derived from actual counts; no fake data or health metaphor is used. Yesterday's comparison, the daily achievement, the weekly strip, native score sharing, and Instagram entry complete the screen. The generic break timer was removed.

Onboarding explains scoring and the supported app, provides an editable initial target, and discloses Accessibility before opening system settings. Tracking and notifications remain optional. Profile exposes history, tracking status, overlay controls, notification controls, update channel, installed version, and a concise data explanation.

League explains that higher counts rank first, displays all returned entries, and retains signed-out, loading, empty, stale, and retry states. Signing in shares the display name and aggregate scores; the UI must not claim everything stays exclusively on-device.

Mochi uses original eyes and a smile, shared visually between Home and the optional session overlay. The companion gains a crown at higher daily levels. The progression is cosmetic and resets with the local calendar day. Existing milestone animations and overlay reduced-motion controls remain.

The GitHub distribution supports stable and beta update channels. Channel changes clear pending installers and reject callbacks from the previous channel. Published build codes allow a newer stable release to replace a beta. APK package, certificate, size, and version checks remain required before installation. Android confirms installation. The Play distribution has no GitHub updater.

Device visual review and real service integration testing remain release gates; see the research document's acceptance list.
