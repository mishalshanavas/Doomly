# Doomly interface

White, black and neutral gray. Platform sans-serif throughout. Headings 32sp,
main count 64sp, body 16sp. Screen gutters 24dp; controls at least 48dp.
Light by default, with a persisted dark appearance option in Profile.

Today prioritizes count, goal, history and tracking. Profile contains progression
and settings. Research uses a native reader with source links and a settings sheet.
Instagram requires its own full-size web login before floating mode can activate.
Linked scroll and pause controls are experimental until verified on a device;
Instagram authentication and DOM behavior are outside Doomly's control.

No extra permissions, backend changes or release workflow changes.
